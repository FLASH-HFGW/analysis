# Step 1 — tono coerente stazionario

Primo modello didattico: cavità a singolo polo, tono in risonanza, conversione IQ
ideale a IF=1 MHz, ADC nominale a 16 bit ±5 V, senza rumore o transiente iniziale.
`validate_step01.py` contiene i controlli analitici e genera le figure.
Eseguirlo in una copia fuori dal repository: salva i prodotti nella propria directory.
Per lo stato attuale del confronto con i dati vedere [README generale](../README.md).
